# Язык LBS

## Как должна выполняться программа

Входом служит текст одной LBS-программы из стандартного ввода. Обработка идёт
в четыре этапа:

1. `lexer.py` превращает символы в токены: числа, имена, ключевые слова и
   операторы.
2. `parser.py` строит дерево из выражений и команд.
3. `compiler.py` переводит дерево в линейную последовательность инструкций.
4. `virtual_machine.py` исполняет инструкции на стеке и в конце выводит
   значения переменных.

Таким образом, несмотря на историческое название `Compiler`, LBS не создаёт
машинный файл: это интерпретатор с промежуточным байткодом.

## Синтаксис

Переменная — одна латинская буква от `a` до `z`. Присваивание и обычное
выражение заканчиваются точкой с запятой:

```lbs
a = 2;
b = a + 3;
```

Несколько команд объединяются фигурными скобками:

```lbs
{
    a = 2;
    b = 3;
}
```

Условные команды и циклы имеют C-подобную форму:

```lbs
if (a < b) a = b;
if (a == b) a = 1; else a = 2;

while (a < 10) a = a + 1;
do a = a - 1; while (a > 0);
```

Поддерживаются `+`, `-`, `*`, `/`, `**` и скобки. Операции сравнения `<`,
`==` и `>` дают `1` для истины и `0` для лжи; эти значения используются в
условиях и циклах. Неинициализированная переменная читается как `0`.

У языка намеренно небольшой учебный объём: нет строк, функций, ввода во время
выполнения, комментариев и многобуквенных имён. Отдельной команды печати тоже
нет — после остановки виртуальная машина показывает итоговые значения
переменных.

## Грамматика

Упрощённо грамматика выглядит так:

```text
program     := statement EOF
statement   := "if" "(" expression ")" statement ("else" statement)?
             | "while" "(" expression ")" statement
             | "do" statement "while" "(" expression ")" ";"
             | "{" statement* "}"
             | expression ";"
             | ";"
expression  := assignment | comparison
assignment  := variable "=" expression
comparison  := arithmetic (("<" | "==" | ">") arithmetic)?
arithmetic  := number | variable | "(" expression ")" | binary-operation
```

Пример [examples/powers.lbs](../examples/powers.lbs) демонстрирует блок,
присваивание, цикл и возведение в степень.
