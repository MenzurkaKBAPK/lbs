# LBS

LBS — учебный язык программирования, созданный для школьного проекта «На чём
написаны языки программирования». Проект показывает полный путь программы:
исходный текст разбирается в синтаксическое дерево, компилируется в простой
байткод и выполняется собственной стековой виртуальной машиной.

## Быстрый запуск

LBS не использует сторонние библиотеки. Нужен Python 3.10 или новее.

```powershell
$env:PYTHONPATH = "src"
Get-Content -Raw examples/powers.lbs | python -m lbs
```

В Linux и macOS тот же пример можно запустить так:

```bash
PYTHONPATH=src python -m lbs < examples/powers.lbs
```

Результатом работы являются значения переменных после завершения программы:

```text
Execution finished.
a = 65536
b = 12347
```

## Возможности

- целые числа и односимвольные переменные `a`–`z`;
- арифметика: `+`, `-`, `*`, `/`, `**`;
- сравнения: `<`, `==`, `>`;
- ветвления `if` и `if ... else`;
- циклы `while` и `do ... while`;
- последовательности команд в `{ ... }`.

Подробное описание синтаксиса и устройства интерпретатора находится в
[docs/language.md](docs/language.md). Исходный документ и презентация школьного
проекта сохранены в каталоге `docs`.
