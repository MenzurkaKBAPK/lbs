# lbs

Язык, написанный специально для проекта по информатике за 10 класс по теме "На чем написаны языки программирования"


## Основа

За основу был взят уже готовый компилятор. У него были те же классы с подобной реализацией, однако я дополнил его несколькими возможностями и разделил на модули


## Возможности

Язык имеет следующие структуры:
- циклы
  - do while
  - while
- условия
  - if
  - if else
- присваивание переменных
- логические операции
  - меньше (<)
  - равно (==)
  - больше (>)
- математические операции
  - плюс (+)
  - минус(-)
  - умножить (*)
  - поделить (/)
  - возведение в степень (**)


## Итоги

Сам по себе язык не имеет какой-либьо ценности, но в процессе написания я получил ценный опыт и понял как работают языки программирования.
